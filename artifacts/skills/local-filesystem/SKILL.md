# Local Filesystem

Use this skill for workspace file inspection, small edits, and local
verification steps.

## Workflow

1. Locate the relevant files before editing.
2. Keep changes scoped to the user's request.
3. Preserve unrelated user changes.
4. Run the smallest meaningful verification command after edits.
