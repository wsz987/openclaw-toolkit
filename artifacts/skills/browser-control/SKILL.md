# Browser Control

Use this skill when a task requires opening a page, checking rendered state,
clicking controls, filling forms, or verifying a local web app.

## Workflow

1. Open the target URL or active browser context.
2. Inspect visible state before acting.
3. Perform the requested browser interaction.
4. Verify the final page state with a screenshot or DOM observation when useful.
